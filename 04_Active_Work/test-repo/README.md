## Welcome to Project2Jarvis!

This repository is part of an experimental AI agency system that uses **OpenCode** with multiple specialized AI agents working together to build, research, and maintain software projects.

### 🎯 What is Project2Jarvis?

Project2Jarvis is a multi-agent AI system featuring:

- **10 Specialized Agents** - Each with unique roles and expertise
- **Council System** - Collaborative review agents for quality, security, performance
- **Autonomous Agents** - Builder, Researcher, and Maintainer with full system access
- **3-Layer Memory** - Persistent memory across sessions (MEMORY.md → Knowledge Base)
- **MCP Integration** - Extensible via Model Context Protocol servers
