## Key Findings

### Similarities
- Both use markdown files with YAML frontmatter for agent definitions
- Same directory structure: `.claude/agents/` (Claude Code) vs `.opencode/agents/` (ours)
- Same skills system with `SKILL.md` files
- Both support rules files: `CLAUDE.md` vs `AGENTS.md`
- Same constraint: subagents cannot spawn nested subagents

### Differences
| Feature | Claude Code | Project2Jarvis |
|---------|-------------|----------------|
| Peer-to-peer agents | Yes (Agent Teams, experimental) | No |
| Inter-agent messaging | SendMessage tool | No native messaging |
| Git isolation | Worktree per agent | Single branch |
| Feature flags | Yes (experimental features) | No (all features enabled) |

### Insights
- Our system is simpler but fully operational
- Claude Code's advanced features are still experimental (disabled by default)
- Both systems separate agents, skills, and documentation into distinct directories
- Anthropic used 16 parallel agents to build a 100K-line C compiler (~$20K cost)
